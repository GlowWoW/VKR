В бакалаврской работе представлена разработка системы, обеспечивающая сбор, хранение и редактирование сведений об успеваемости студентов кафедры ИСТ. Система создана с целью организации и систематиза-ции хранения данных о студентах, учащихся на кафедре и систематизации информации в учебных ведомостях.
Информационная система состоит из базы данных и приложения.
Приложение предназначено для использования сотрудниками кафедры. Основными функциями являются редактирование ведомостей об успеваемости в электронном формате и формирование различных отчетов на основе этих ведомостей.
Для разработки использована операционная система Windows 10, среда исполнения – 1С:Предприятие 8.3
